# Quran Mushaf — Madani pages (WebP)

604 страницы Мединского Мусхафа (Hafs 'an 'Asim) в формате WebP для оффлайн-ридеров.

- **Источник:** [batoulapps/quran-svg](https://github.com/batoulapps/quran-svg) (MIT) — официальные
  векторные файлы Королевского комплекса печати Корана (KFGQPC), конвертированы в SVG.
- **Здесь:** SVG → WebP, ширина 1200px, quality 82.
- **Имена файлов:** `001.webp` … `604.webp` (3 цифры с ведущими нулями).
- **Разрешение:** ~1200×1715 (портрет).

## Прямой доступ (jsDelivr)

```
https://cdn.jsdelivr.net/gh/taulujas-png/quran-mushaf@main/{page3}.webp
```

`{page3}` — номер страницы с ведущими нулями (например `293.webp` → `https://cdn.jsdelivr.net/gh/taulujas-png/quran-mushaf@main/293.webp`).
